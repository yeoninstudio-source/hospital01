# ○○피부과 홈페이지

seoultone.kr 의 **구조·레이아웃·인터랙션·디자인 톤**을 그대로 재현한 피부과 홈페이지입니다.
상호·원장명·전화번호·주소·사진 등 실제 병원을 특정하는 정보는 모두 플레이스홀더로 넣어두었습니다.

## 실행

```bash
node server.js
```

`http://localhost:5177` 로 접속하면 됩니다. (파일을 직접 열어도 되지만, 로컬 서버로 봐야 캐시 문제 없이 확인됩니다.)

## 파일 구조

```
clinic-site/
├─ index.html            메인 페이지
├─ pages/intro.html      서브페이지 템플릿 (병원소개/의료진/장비/이벤트/오시는길)
├─ assets/
│  ├─ css/style.css      전체 스타일 (reset → 공통 → 헤더 → 섹션 → 반응형 → 서브페이지)
│  └─ js/main.js         전체 스크립트 (라이브러리 의존 없음, 순수 JS)
├─ server.js             로컬 확인용 정적 서버
└─ .claude/launch.json   미리보기 설정
```

## 구현된 인터랙션

전부 순수 JavaScript입니다. jQuery, Swiper, ScrollReveal 같은 외부 라이브러리를 쓰지 않습니다.

- 메인 슬라이더: 6초 자동 전환, 페이저 클릭 이동, 진행바 리셋, 탭 비활성화 시 정지
- 헤더: 스크롤 60px 이상에서 흰 배경 전환, 메가 드롭다운 위치 자동 정렬
- 모바일(1200px 이하): 햄버거 드로어 + 1단계 아코디언, 열릴 때 body 스크롤 잠금
- 스크롤 등장: IntersectionObserver 기반 페이드 업
- TOP 버튼: 400px 이상에서 노출

## 반응형 분기

- `1400px` 이하 — 헤더 높이 축소, 타이틀 크기 축소
- `1200px` 이하 — 모바일 메뉴 전환, 2단 레이아웃 → 1단
- `768px` 이하 — 모바일 최적화 (카드 가로형 전환, 버튼 풀폭)

| 찾을 문자열 | 바꿀 내용 |
|---|---|
| `○○피부과` | 실제 병원명 |
| `OO DERMATOLOGY` | 영문 병원명 |
| `홍길동` | 대표원장 성함 |
| `02-0000-0000`, `010-0000-0000` | 실제 전화번호 (`tel:` 링크 포함) |
| `서울특별시 강남구 ○○로 00, 0층` | 실제 주소 |
| `contact@example.com` | 실제 이메일 |
| `000-00-00000` | 사업자등록번호 |
| `clinicname` | SNS 계정 ID |
| `href="#"` | 네이버예약 / 카카오채널 / SNS 실제 링크 |

### 이미지 교체

- 메인 비주얼 배경 5장 — `style.css` 의 `.hero_slide[data-bg="1"] .bg` ~ `[data-bg="5"]` 의 `background` 를 `url()` 로 교체
- 나머지 `.ph_box` 회색 박스 — 실제 `<img>` 태그로 교체
- 로고 — 현재 텍스트 로고(`.logo_kr` / `.logo_en`), SVG 파일이 있으면 `<img>` 로 교체

### 지도

`.ph_box.map` 자리에 카카오맵 또는 네이버지도 임베드 스크립트를 넣으면 됩니다.

## 남은 작업 (필요 시)

- 서브페이지는 `pages/intro.html` 하나를 템플릿으로 만들어 두었습니다. 나머지 시술 페이지(시그니처 8종, 리프팅 7종 등)는 이 파일을 복제해서 내용만 바꾸면 됩니다.
- 게시판(이벤트/공지) 기능은 정적 마크업만 있습니다. 실제 운영하려면 백엔드나 CMS 연동이 필요합니다.
